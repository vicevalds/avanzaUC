### Miniconda3
```bash
curl -O https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh -b
rm Miniconda3-latest-Linux-x86_64.sh
. ~/miniconda3/bin/activate
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/main
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/r
```
### REINVENT
```bash
git clone https://github.com/MolecularAI/REINVENT4
conda create --name reinvent4 python=3.11 -y
conda activate reinvent4
cd REINVENT4
python3 install.py cu124
pip uninstall -y torch torchvision torchaudio
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
```
### Maize for use plugins
```bash
git clone https://github.com/MolecularAI/maize-contrib
cd maize-contrib
conda env create -f env-users.yml -y
conda activate maize
pip install --no-deps ./
```
### Make MSA
```bash
conda create --name colabfold python=3.10
conda activate colabfold
pip install colabfold
colabfold_batch <pdb_code>.fasta path/to/output/folder --msa-only --host-url https://api.colabfold.com
```

## Run TL
```bash
. ~/miniconda3/bin/activate
conda activate reinvent4
mkdir -p results/out_TL
reinvent -l results/out_TL/TL.log TL.toml
conda activate tensorboard
tensorboard --logdir=results/out_TL/tb_TL
```
